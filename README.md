# Customer Segmentation Using RFM Analysis and K-Means Clustering

## Project Overview

This project implements customer segmentation using **Recency, Frequency, and Monetary (RFM) Analysis** combined with the **K-Means Clustering algorithm**.

The objective of this project is to transform transactional data into customer behavior insights by identifying customer segments based on purchasing patterns.

The analysis follows the **Cross-Industry Standard Process for Data Mining (CRISP-DM)** methodology, covering business understanding, data preparation, modeling, evaluation, and deployment.

---

## Business Problem

Transactional data collected through Point of Sale (POS) systems often functions only as operational records. Without further analysis, this data cannot provide deeper insights regarding customer behavior and business strategy.

This project focuses on utilizing transaction history data to:

- Understand customer purchasing behavior.
- Identify customer groups based on transaction patterns.
- Recognize high-value customer segments.
- Support customer retention and marketing strategy development.

---

## Project Objectives

The objectives of this project are:

- Transform raw transaction data into customer-level behavioral features.
- Generate customer profiles using RFM analysis.
- Segment customers using K-Means Clustering.
- Evaluate clustering performance using validation metrics.
- Provide business recommendations based on customer characteristics.

---

# Methodology

This project applies the **CRISP-DM (Cross Industry Standard Process for Data Mining)** framework.

## 1. Business Understanding

Identify business challenges related to customer retention and the utilization of transaction data.

## 2. Data Understanding

Analyze transaction data structure, customer information, and data quality before processing.

## 3. Data Preparation

The preprocessing stage includes:

- Data cleaning
- Missing data handling
- Customer identity standardization
- Transaction and customer data integration
- Feature transformation
- Outlier detection
- Feature selection

## 4. Modeling

Customer segmentation is performed using:

- RFM Feature Engineering
- K-Means Clustering

The clustering variables consist of:

| Feature | Description |
|---|---|
| Recency | Number of days since the customer's last transaction |
| Frequency | Total number of transactions performed by the customer |
| Monetary | Total customer spending value |

## 5. Evaluation

The clustering results are evaluated using:

- Elbow Method
- Silhouette Coefficient

## 6. Deployment

The final segmentation results are visualized using an interactive dashboard to support business decision-making.

# RFM Analysis

RFM analysis is used to represent customer purchasing behavior through three main attributes:

## Recency

Measures how recently a customer performed their latest transaction.

## Frequency

Measures how often a customer makes transactions during the observation period.

## Monetary

Measures the total transaction value generated by each customer.

---

# Machine Learning Approach

## K-Means Clustering

K-Means is an unsupervised machine learning algorithm used to group customers with similar purchasing characteristics.

The optimal number of clusters is determined using the Elbow Method and validated using Silhouette Coefficient.

---

# Model Evaluation

## Elbow Method

The Elbow Method is applied to determine the optimal number of clusters by analyzing the reduction of Sum of Squared Errors (SSE).

## Silhouette Coefficient

The final clustering performance achieved:

Optimal Cluster: 2

Silhouette Coefficient:
0.7287


The result indicates that the generated clusters have a strong separation structure.

# Customer Segmentation Result

The analysis generated two main customer segments.

## Segment 1 - Potential Customers

Characteristics:

- Lower transaction frequency.
- Lower average spending value.
- Less recent purchasing activity.

Recommended strategies:

- Customer reactivation campaigns.
- Promotional offers.
- Personalized communication to encourage repeat transactions.

---

## Segment 2 - Priority Customers

Characteristics:

- Higher transaction frequency.
- Higher spending contribution.
- More recent purchasing activity.

Recommended strategies:

- Loyalty program optimization.
- Exclusive promotions.
- Reward-based retention programs.
